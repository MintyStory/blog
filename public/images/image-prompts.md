# 이미지 제작 프롬프트 — 260915 블로그 홈

공통 스타일: 안정적·모던·깔끔·신뢰감 있는 에디토리얼 톤. 과포화 없는 자연광, 딥블루(#1E3A8A)와 화이트가 배색에 섞이는 무드. 인물이 등장할 경우 자연스러운 표정, 과한 포즈 없음. 텍스트/로고 없이 순수 사진.

파일 저장 규칙: 생성된 이미지는 아래에 지정된 파일명 그대로 이 문서와 같은 `images` 폴더에 WebP 형식으로 저장. 웹페이지에서는 `images/파일명.webp` 경로로 연결.

## 1. 히어로 배경 (풀블리드, 다크 오버레이 적용됨)
**용도:** 최상단 히어로 섹션 배경
**비율:** 16:9 이상 와이드, 최소 2400×1350px
**파일명:** `hero-developer-workspace.webp`

> 모던한 사무실 또는 홈 데스크 셋업에서 개발자가 노트북 화면을 바라보며 코드를 작성하는 모습, 측면 또는 뒷모습 구도, 창문에서 들어오는 차분한 자연광, 딥블루와 그레이 톤의 미니멀한 인테리어, 여백이 넓은 와이드 프레이밍, 다큐멘터리 사진 스타일, 35mm 필름 느낌의 절제된 색감, 인물 얼굴은 크게 드러나지 않게, 신뢰감 있고 차분한 무드.

## 2. 마무리 무드 섹션 배경 (풀블리드, 다크 오버레이 적용됨)
**용도:** 최하단 클로징 섹션 배경
**비율:** 16:9 이상 와이드, 최소 2400×1350px
**파일명:** `closing-night-workspace.webp`

> 해질 무렵 또는 야간, 모니터 불빛만 켜진 조용한 작업 공간을 넓게 담은 와이드샷, 디테일보다 분위기 중심, 딥네이비·블랙 톤의 로우키 조명, 미니멀하고 정제된 구도, 인물은 작게 실루엣으로만 등장하거나 생략 가능, "하루를 마무리하는" 잔잔하고 사색적인 무드.

## 3. 카테고리 카드 — Frontend
**용도:** 카테고리 그리드 1번 카드 (4:5 비율)
**비율:** 4:5, 최소 1200×1500px
**파일명:** `category-frontend.webp`

> 노트북 화면에 UI 컴포넌트와 컬러 팔레트가 떠 있는 모습을 위에서 내려다본 클로즈업, 화면 속 인터페이스는 심플하고 정돈된 레이아웃, 책상 위 미니멀한 소품(마우스, 노트) 약간 노출, 밝고 깨끗한 화이트 톤 배경, 수직 프레이밍.

## 4. 카테고리 카드 — Backend
**용도:** 카테고리 그리드 2번 카드 (4:5 비율)
**비율:** 4:5, 최소 1200×1500px
**파일명:** `category-backend.webp`

> 어두운 배경의 터미널/코드 에디터가 켜진 모니터를 정면에서 살짝 비스듬히 촬영, 화면의 모노스페이스 코드 텍스트가 흐릿하게 보이는 정도, 모니터 빛이 얼굴이나 손에 반사되는 로우키 조명, 차분한 블루 톤 그레이딩, 수직 프레이밍.

## 5. 카테고리 카드 — Infra
**용도:** 카테고리 그리드 3번 카드 (4:5 비율)
**비율:** 4:5, 최소 1200×1500px
**파일명:** `category-infra.webp`

> 서버랙 또는 네트워크 장비, 혹은 클라우드 인프라를 상징하는 여러 대의 모니터에 그래프/대시보드가 떠 있는 모습, 기계적이고 정돈된 구도, 차가운 블루톤 조명, 클린하고 기술적인 느낌, 수직 프레이밍.

## 6. 인기글 캐러셀 카드 (공통 스펙, 5장)
**용도:** "많이 읽은 글" 가로 스크롤 카드
**비율:** 4:5, 최소 1000×1250px (5장 모두 동일 비율)

1) **React 렌더링 최적화**  
   **파일명:** `popular-react-rendering.webp`  
   브라우저 개발자도구의 퍼포먼스 탭이 열려 있는 모니터 클로즈업, 그래프와 타임라인이 보이는 화면, 차분한 블루 그레이 톤.

2) **타입스크립트 제네릭**  
   **파일명:** `popular-typescript-generics.webp`  
   코드 에디터에 타입 정의 코드가 떠 있는 화면을 가까이서 촬영, 심플한 신택스 하이라이팅, 깨끗한 화이트 데스크 배경.

3) **느린 API 최적화 기록**  
   **파일명:** `popular-api-optimization.webp`  
   네트워크 요청/응답 로그가 떠 있는 콘솔 화면, 손이 키보드를 타이핑하는 모습이 함께 담긴 미드샷.

4) **CI/CD 파이프라인 구축기**  
   **파일명:** `popular-cicd-pipeline.webp`  
   빌드/배포 파이프라인 다이어그램이 모니터에 떠 있는 화면, 여러 단계의 초록/파란 상태 표시가 보이는 구도.

5) **사이드 프로젝트 1년 회고**  
   **파일명:** `popular-side-project-retrospective.webp`  
   노트북과 다이어리, 커피 한 잔이 함께 놓인 책상 전체를 담은 잔잔한 오버헤드 샷, 회고와 기록의 정서.

공통 톤: 모든 이미지는 딥블루·그레이·화이트 톤으로 통일, 과한 장식 없이 실제 작업 환경을 담은 다큐멘터리 스타일.

## 7. 최신글 비대칭 갤러리 카드 (공통 스펙, 5장)
**용도:** "최근에 쓴 글" 섹션 (1장은 1:1 큰 카드, 4장은 4:5 작은 카드)
**비율:** 1번은 1:1 (최소 1600×1600px), 2~5번은 4:5 (최소 1000×1250px)

1) **배포 자동화 (대형, 1:1)**  
   **파일명:** `latest-deployment-automation.webp`  
   여러 모니터에 배포 로그와 인프라 대시보드가 동시에 떠 있는 넓은 작업 공간 전체 샷, 정돈되고 기술적인 무드, 중심 구도.

2) **느린 API 최적화**  
   **파일명:** `latest-api-optimization.webp`  
   인기글 3번과 톤을 통일하되 다른 각도에서 촬영한 콘솔 로그 화면 클로즈업.

3) **React 렌더링 최적화 노트**  
   **파일명:** `latest-react-rendering-notes.webp`  
   손글씨 노트와 모니터 화면이 함께 보이는 책상 샷.

4) **타입스크립트 제네릭 정리**  
   **파일명:** `latest-typescript-generics.webp`  
   코드 에디터 화면 클로즈업, 정돈된 타입 구조.

5) **CI/CD 파이프라인 구축기**  
   **파일명:** `latest-cicd-pipeline.webp`  
   파이프라인 상태 대시보드 화면.
